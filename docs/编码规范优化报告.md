## 2. 本轮实施（S1–S7）

### S1 包结构：事件驱动解耦 route↔config 环，刷新/推送迁入 `refresh` 包

- **问题**：`RouteService`（route 包）直接依赖 `config` 包的刷新/推送组件，而后者又依赖 route 包（`RouteRefreshService`/`ConfigRevisionRepository`）→ 包级循环依赖（评审 F1）；`config` 包职责过载。
- **优化**：
  - 新增 `route/RouteChangedEvent` 领域事件；`RouteService` 与 `SeedDataInitializer` 在**事务提交后**发布事件，不再依赖刷新/推送实现。
  - 新增 `refresh/RouteChangeSyncListener` 统一编排：本地生效路由刷新（含预热）→ 内嵌网关轮询标记 → 外部网关推送。
  - `EmbeddedGatewaySyncScheduler`、`ExternalGatewayRefreshService` 从 `config` 迁入 `refresh` 包（`git mv` 保留历史）。
  - **附带修复**：种子数据原在事务内刷新（可能读到未提交数据），现改为提交后发布事件 → 种子路由立即生效。
- 依赖图变为无环：`route → (self)`，`refresh → route+config`，`config → route`，`gateway → refresh/config/route`。

### S4 审计动作类型化：`AuditAction` 枚举

- **问题**：`AuditService.record(action: String)` 与 `RouteService` 中 4 处动作魔法字符串（"CREATE"/"UPDATE"/"DELETE"/"ENABLE"/"DISABLE"），拼写漂移无编译期保护。
- **优化**：新增 `audit/AuditAction` 枚举；`AuditLog.action` 改 `@Enumerated(EnumType.STRING)`（DB 存储值不变，无需迁移）；`AuditService.record` 与 DTO 签名类型化；`RouteService` 调用点改用枚举。
- **前端联动**：`AuditLogView.actionType` 补上缺失的 `ENABLE → success`、`DISABLE → warning` 映射（此前落入默认灰色）。

### S2 泛型：`RouteAssembler.toSteps(List<? extends Object>)` → `List<?>`

- `List<? extends Object>` 与 `List<?>` 等价但属于坏味道；收紧为 `List<?>`。

### S3 类型安全：`ExternalGatewayStatusService` 强转收敛

- `Mono.zip(monos, Object[] -> (T) item)` 的受检强转收敛到唯一私有泛型助手 `zipAll`，标注 `@SuppressWarnings("unchecked")` 并说明理由；调用侧保持类型安全。

### S5 死参数：`RouteValidator.validate` 移除未使用的 `existingRouteId`

- 签名 `validate(RouteRequest)`，同步更新 `RouteService` 两处调用与 `RouteValidatorTest` 6 处断言。

### S6 配置：`ExternalGatewayProperties` 改 record 构造器绑定

- 由可变 `@Component` 类改为 `record` + `@ConfigurationPropertiesScan`（Boot 3 对 record 自动启用构造器绑定）；`List.copyOf` 防外部修改；嵌套 `Gateway` 同步 record。调用点访问器更新为 `externalGateways()`/`baseUrl()`/`token()`。

### S7 异常处理：`GlobalExceptionHandler` 校验分支去重

- `MethodArgumentNotValidException` 与 `WebExchangeBindException` 两分支（结构相同）合并为统一 `BindingResult` 提取，减少重复。

## 3. 复核通过项（无需改动）

- **命名**：控制器 `*Controller`（[SPRING] 约定）；常量 `MAX_PRIORITY`/`REQUEST_TIMEOUT`/`PUSH_TIMEOUT`/`JSON_COLUMN_LENGTH` 均 UPPER_SNAKE。
- **不可变性**：DTO/请求/响应全 record；`UserAuthStateCache`/`PermissionRuleService` 用 `AtomicReference`/`ConcurrentHashMap` 管理共享态且不可变快照。
- **Optional/流**：仓储 `findByUsername`/`findByRouteId` 返回 Optional + orElseThrow；流管道简短。
- **依赖注入**：全构造器注入（`@RequiredArgsConstructor` 或显式构造器），无字段注入。
- **响应式**：全部阻塞 JPA 经 `BlockingSupport`（boundedElastic）；过滤器/控制器为响应式链；无阻塞泄漏进事件循环。
- **异常**：`BusinessException` 静态工厂 + `GlobalExceptionHandler` 统一出口；无静默吞异常（此前静默点均已修复）。
- **日志**：SLF4J 风格统一；无 System.out/printStackTrace。
- **配置**：敏感值环境变量化 + 启动强校验（prod 无默认值）。

## 4. 遗留可接受项（低价值，不纳入）

| 项 | 说明 |
|---|---|
| `PermissionRuleService.ALLOWED_METHODS` 与 DTO `@Pattern` 白名单重复 | 服务层含归一化（trim/大写）语义，收敛收益低 |
| `DynamicPermissionAuthorizationManager` 的已弃用 API 告警 | Spring Security 6 响应式授权 API 演进，升级版本时统一处理 |
| 控制器构造器风格混用（@RequiredArgsConstructor vs 显式构造器） | 显式构造器均因 @Qualifier 需要，属合理例外 |
| gateway-demo 与 backend 双份平行 `DbRouteDefinitionLocator` | 评审 F4：抽共享模块收益 vs 演示工程独立性，暂不抽 |
