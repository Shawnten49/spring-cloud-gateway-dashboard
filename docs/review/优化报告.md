## 3. 行为变更说明（影响使用方）

1. **启用/停用接口**：`POST /api/routes/{id}/enabled` 请求体必须包含 `{"enabled": true|false}`，否则 400（此前 `{}` 会被静默当作停用）。
2. **权限规则**：
   - 内置规则不可通过 PUT 修改（此前仅 DELETE 拦截）。
   - 任何增删改都会校验 ADMIN 对权限模块全部写端点仍可达（此前只模拟 POST）。
   - `priority` 取值范围 0–999；`roles` 不能为空白。
3. **网关内部接口**（gateway-demo）：`internal-token` 未配置 → 启动失败；token 缺失/错误 → 401。
4. **生产部署**：新增 prod profile，`JWT_SECRET` / `GD_ADMIN_PASSWORD` / `GD_VIEWER_PASSWORD` 缺失或使用开发默认值 → 拒绝启动。
5. **网关状态页**：`effectiveRoutes` 现在是内存中真实生效的路由（CachingRouteLocator），与"保存即生效"语义一致；predicate/filter 明细在运行态不可还原，置空数组。
6. **CORS**：允许来源可配置（`gateway-dashboard.cors.allowed-origins`）。
