# 接口权限规则数据库化、动态生效

接口访问权限（HTTP 方法 + 路径模式 → 允许角色）从 `SecurityConfig` 中的硬编码规则改为数据库 `permission_rule` 表管理，由自定义 `ReactiveAuthorizationManager` 按优先级实时匹配，规则修改后即时生效、无需重启。

理由：新增功能模块时，只需在权限配置页（或数据库）加一条规则，不用改代码重新发布；内置规则种子与 v1 硬编码行为完全一致。代价是权限决策依赖数据库配置，因此提供自我保护——任何规则改动不得导致 ADMIN 失去对权限配置模块的访问权（否则拒绝保存）。
